Royal Burgundy — Denis Isikawa Portfolio

This folder contains an independent, bilingual, responsive static site for GitHub Pages.

To publish: open the repository Settings > Pages > Build and deployment. Choose Deploy from a branch, branch main, folder /docs, and Save. Once the Pages workflow finishes, visit the URL GitHub displays. The expected project URL (only AFTER Pages is enabled) is https://denisisikawa.github.io/denis-isikawa-databricks/ .

The site is dependency-light: HTML with embedded CSS and JavaScript. It includes a functioning English/Portuguese toggle, interactive architecture layers, project filtering, mobile navigation, scroll progress, reduced-motion support, and a custom SVG favicon. It uses Google Fonts with local fallbacks. No tracking or credentials.

Run locally from the repository root: python -m http.server 8000 ; then open http://localhost:8000/docs/ .

Portfolio examples use synthetic data. Current certification preparation is not a credential. No employer production deployments are claimed.
