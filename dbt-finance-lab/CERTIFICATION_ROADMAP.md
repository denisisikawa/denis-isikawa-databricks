# Databricks certification roadmap

> **Plan only. No certificate or production Databricks execution is claimed.**

## Goal
Combine practical dbt Analytics Engineering skills with a possible Databricks credential to strengthen Finance Data Architect / FP&A Data & Analytics positioning. Assess actual job requirements before paying for an exam.

| Weeks | Skill focus | Evidence |
| --- | --- | --- |
| 1–2 | dbt seeds, models, refs and tests | local green build + docs |
| 3–4 | source freshness, reconciliation and data contracts | financial quality case |
| 5–6 | Delta Lake, Unity Catalog, SQL and orchestration concepts | architecture decision record |
| 7–8 | Official Data Engineer Associate exam objectives | skill-gap checklist and practice |
| Later | Advanced production concepts, if relevant | assess Professional readiness |

## Certification decision rules
- Use the **current** exam guide; prices, validity, objectives and formats may change.
- Prioritize being able to explain and demonstrate each objective over memorizing terms.
- Consider **Data Engineer Associate** as the first checkpoint if platform knowledge needs formal validation.
- Consider **Data Engineer Professional** after substantial operational and production-level knowledge.
- **Never add a credential to CV/LinkedIn until it is earned.**

Official links: [Databricks certification](https://www.databricks.com/learn/certification), [Data Engineer Associate](https://www.databricks.com/learn/certification/data-engineer-associate), [Data Engineer Professional](https://www.databricks.com/learn/certification/data-engineer-professional), [dbt docs](https://docs.getdbt.com/).
